## 2. 数据（Data）

### 2.1 词条（共享词库，部分 1：阅读材料）

手册约 1,785 个单词条目 + 词组条目，存为共享词库 `content/lexicons/zkv/entries/<entryId>.json`（按首字母分文件也可），条目由多个日条目引用，**不在每天的 item 里复制**。

```jsonc
{
  "id": "e-advice",                       // 永久 ID：e- + 小写词头（词组用连字符）
  "kind": "word" | "phrase",
  "headword": "advice",
  "ipa": ["ədˈvaɪs"],                     // 可多个（英/美）
  "star": true,                            // *：考纲重点
  "levelMark": "▶" ,                      // ▶：考纲中的三级词汇（可空）
  "textbook": ["G7上U4"],                  // 沪教版教材出现位置
  "senses": [{ "pos": "n.", "zh": "忠告，劝告，建议，意见" }],
  "inflections": "（复 abilities）",        // 如有
  "examples": [{ "en": [Inline...], "zh": "经理认为……" }],   // en 中词头用 underline 节点，与原书一致
  "phrases":   [{ "en": "take one's advice", "zh": "听从某人劝告" }],          // ☞ 常用词组
  "wordFamily":[{ "word": "advise", "pos": "v.", "zh": "劝告，忠告，建议" }],   // ☞ 词形拓展
  "synonyms":  ["opinion", "suggestion"],  // 近义
  "antonyms":  ["disadvantage"],           // 反义
  "proverbs":  [{ "en": "Every advantage has its disadvantage.", "zh": "有利就有弊。" }],
  "tip":       [Block...],                 // 名师点拨（富文本框）
  "audio":     { "word": "…mp3", "examples": ["…mp3"] },   // TTS 生成（原书音频需扫码，不可得）
  "source":    { "pdf": "…用法手册….pdf", "bookPage": 5 }
}
```

### 2.2 每天的条目（部分 2：题目）

```jsonc
{
  "format": "vocab-day", "id": "zkv-d01", "playlistId": "zkv", "order": 1, "day": 1,
  "title": "ability – against",              // 只写当天词条范围；「第1天 / Day 1」由界面按语言加（uniread-spec/i18n）
  "wordRange": { "from": "e-ability", "to": "e-against" },   // Vocabulary 标签按此取词条
  "sections": [ /* 一–六大题，见下表 */ ],
  "meta": { "totalPoints": 100, "suggestedMinutes": 25 }
}
```

| 大题（分值） | 题干 | 作答形状 | 题型（kind） | 新 / 复用 |
|---|---|---|---|---|
| 一 根据音标写单词、词性、中文（10） | IPA | `{word, pos, zh}` | **`wordProfile`**：英文拼写 + 词性选择 + 中文释义 | 新 |
| 二 根据中文写英文单词（30） | 中文 + 词性 | 单词 | `textEntry` | 复用 |
| 三 根据单词和词性写相关词及释义（20） | 词 + 词性，列出目标词性槽位 | `[{word, zh}]` 每槽一组 | **`wordFamily`** | 新 |
| 四 用所给词的适当形式填空（10） | 句子 + （原词） | 单词 | `textEntry`（`hint.base`） | 复用 |
| 五 首字母填空（10） | 句子 + 首字母 | 单词 | `textEntry`（`hint.firstLetter`，已有） | 复用 |
| 六 中译英（20） | 中文 + （指定词） | 句子 | `extendedText`（`scoring:"judge"`，`requiredWord`） | 复用 + 增量字段 |

**词组日（约第 58–70 天，考纲词组）** 结构不同，只有三个大题：

| 大题（分值） | 题干 | 作答形状 | 题型（kind） | 新 / 复用 |
|---|---|---|---|---|
| 一 根据中文写英语词组（50） | 中文义项 | 词组（多词） | `textEntry`（多词，规范化空格与 sb./sth. 写法） | 复用 |
| 二 选择适当的词组译成英文填空，每个词组只能填一次（20） | 句子 + 方框里的中文词组表（含 1 个干扰项） | 英文词组（按句子变形） | `textEntry` + section `bank`（中文提示表，已用的标记为已用，不点选） | 复用 + 增量 |
| 三 中译英（30） | 中文 + （指定词组） | 句子 | `extendedText`（`requiredWord`） | 同单词日六 |

**表格日（第 69–70 天）**：原书印的是带空格的表格（人称代词 / 物主代词 / 反身代词表、基数词与序数词表、不规则动词表），另有国家名称一大题（普通 `textEntry`）。
- 表格放在 section 的 `stimulus`（`table` 块），每个答案格是一个 `blank`；每行（代词表为每格）是一道 `textEntry`，`blankIds` 列出它在表格里的空，不另设 `prompt`。作答时只显示表格，复盘时表格下面逐题列出答案和解析。
- 印成空白、原书答案也空着的格（can / may / shall / will 的过去分词）不设空。
- `entryIds` 是表格里在手册中有词条的词，按手册编号排列；`wordRange` 取其首尾。表格日不是一段连续的词条，`validate` 不报编号跳号。标题取表格中的首词和末词（`I – forget`、`freeze – will`）。
- 第 70 天 91 个动词平分原书的 100%（每题 100/91 分）。
- 生成脚本：`.work/batch/tables/gen.py`（本地，不交付）。

- Key（`content/playlists/zkv/keys/`）：一、三的中文释义给出**全部可接受义项**（取自书末答案 + 手册义项）；二、四、五给出全部可接受拼写；六给出全部参考译文（书中「A = B」拆为多条）。
- 每题记录 `entryRef`（对应词条），用于错题解析。
- 新增 kind 与字段全部为**增量**：`SCHEMA_VERSION` 不变；新增 `format: "vocab-day"`、`lexicon` 词库类型。

### 2.3 判分

| 内容 | 规则 |
|---|---|
| 英文单词（一、二、三、四、五） | 忽略大小写和首尾空格；拼写必须完全正确（考的就是拼写）；接受 key 列出的所有拼写。只差一个字母时提示「差一点」但不给分 |
| 词性（一） | 选择题，精确匹配（`n.` `v.` `adj.` `adv.` `prep.` `conj.` …） |
| 中文释义（一、三） | 先本地规范化（去标点、括号、「的」）后与可接受义项比对，答出任一义项即对；不命中再交给现有 LLM judge（「意思对即对，词性义项不能张冠李戴」） |
| 中译英（六） | 现有 LLM judge：对照全部参考译文，分档给分，**必须用到指定词**；判分在服务端 |
| 分数 | 按书上分值折算为 100 分；通过线沿用 Quiz 结果页的 pass rate（建议 60%） |

## 3. 交互（Interaction）

### 3.1 进入一天：三步（#133）

顶部标签「**Scan** | **Study** | **Quiz**」（中文界面「速览 | 学习 | 测验」；按钮「认识 / 不认识」对应 Know / Don't know）：先扫一遍标出认识 / 不认识，再有针对性地学，最后测。全部界面文案按 [UniRead i18n 规范](uniread-spec/i18n.md) 有中英两套完整版本，由宿主切换（下文用英文名指称三个步骤）。打开一天时落在学生停下的那一步：Quiz 已有作答 → Quiz；当天词都标过 → Study；否则 Scan（从第一个没标的词开始）。从 Quiz 的错题可以跳回对应词条。

### 3.1a Scan 标签

- 一页一个词，居中只显示**词头和音标**；下方两个按钮「认识 / 不认识」（Know / Don't know），点了记下并翻到下一个词。
- 底部页码「当前 / 总数」（如 10/34），左右箭头可以回看、改标注；当前标注在按钮上高亮。
- 标完最后一个词显示小结（认识 N · 不认识 M），按钮「去学习」进 Study、「从头再看」。
- 标注存在作答记录 `known`（只存本地，不计分）；「只练错题」重做时保留。

### 3.2 Study 标签（只读）

- **布局：词典条目列表**（对标 Oxford Learner's / Cambridge 词典页，不用单卡翻页）：约 30 条一屏滚动，每条显示词头、音标、★、教材标签、词性 + 中文、例句（词头下划线 + 中文）；词组 / 词形拓展 / 近反义 / 谚语默认折叠，名师点拨常显。理由：内容来自纸质手册，学生习惯翻看；30 条单卡要翻 30 次；错题需要锚点定位到条目。
- **音频**：词头和每个例句都有播放按钮，不自动播放。词头和例句的播放按钮同一样式（#131）。
- **发音标准（#131，所有词汇类内容）**：TTS 生成的词头和例句里的该词，一律按**原书该词条印的音标**发音，不交给 TTS 自行判断（一词多音如 adult /ˈædʌlt/ 与 /əˈdʌlt/；TTS 也会读错单一发音的词，如 affect）。流程：
  1. `node scripts/lexicon-pron.mjs <lexicon>`：把印刷音标转成 ARPAbet，写入 `content/lexicons/<lexicon>/pronunciations.json`。CMU 词典的读法只在**与印刷音标一致**时采用：辅音相同（英式音标省略的 r、/djuː/ 的 j 除外），元音逐个同质（英式 ↔ 美式对应，如 ɒ ~ AA/AO；ɑː 不改成美式 æ），主重音在同一音节。不一致时（zebra /ˈzebrə/、conduct /kənˈdʌkt/、of /ɒv/ 等）以印刷音标为准，只借用词典里的美式 r。例句中下划线的词形（adults、affected…）取最接近词头读法的词典读法。**印了多个音标的单词**（object /əbˈdʒekt/ /ˈɒbdʒɪkt/、and /ənd/ /ən/，#131 第三轮）和**有变体的词头**（a (an)、although / though、colour (color)、toward(s)）及带音标的词组，词头音频按印刷的每个音标依次读（a (an) 读 /eɪ/、/ə/），不按拼写读；例句交给 TTS。
  2. `node scripts/tts.mjs --lexicon <lexicon>`：用 SSML `<phoneme alphabet="cmu">` 交给火山 TTS，只重做送去合成的内容有变化的片段（`.work/tts/<lexicon>.json` 记录每段的合成输入）。这个音色的 phoneme 支持不完全，2026-11 实测：CMU 的 AH0（ə）会读成全元音（affect 读成 /ˈæfekt/，与 SSML 无关），音素串与词典读法相同时会退回该词的默认读法。所以 ə 以 AX 送出。**同一请求里同一个拼写只读一种**：either 先后按 /ˈaɪðə/、/ˈiːðə/ 标注，读出来两遍都是 /ˈaɪðə/（`<break>`、句号都无效），所以多个读法逐个单独合成，再用 `scripts/py/join_audio.py` 拼成一段（间隔 0.45 s；venv 需 `pip install lameenc`）。**这个音色读不出的**：单独成词的弱读式（a /ə/、and /ən/、her /hə/、them /ðəm/ 等，任何只有一个元音的标注都会被重读，/ə/ 变成 /eɪ/ 或 /æ/；单独的 /ə/ 现送 "uh"，读成拖长的感叹词 /ʌː/，约 0.5 s，并非弱读 ə），以及重音在后的词首弱读音节（object /əb-/、compound /kəm-/、protest /prə-/ 读成全元音）；从句子里截取弱读式只有 70–120 ms，过短。这些交给**第二个引擎 Azure Speech**（`scripts/lib/azure-tts.mjs`，en-US 神经音色，`<phoneme alphabet="ipa">`，凭据 `AZURE_SPEECH_KEY` / `AZURE_SPEECH_REGION` 写在 `.env.local`）：含单音节弱读式的词条直接用 Azure；其余词条火山各种方式都核验不过时，最后再试 Azure。用 Azure 的词条，整段词头音频（所有读法）都由 Azure 读，同一段里不换声音。Azure 单独的 /ə/ 约 0.16–0.21 s、央元音，是真正的弱读 ə。
  3. **合成后逐条核验**：每段新做的词头音频都用音素识别模型（wav2vec2 espeak，`scripts/lib/pron-check.mjs`，首次安装见文件头）听一遍，与印刷音标逐个元音比对：音节数、印 ə 处是否弱读、全元音音质。不一致的依次换 `cmu`、`plain`（TTS 自己的读法）、`ax`、`azure`（Azure 音色）再做，取第一个一致的，写入 `pronunciations.json` 的 `voice`。都不一致的列在 `.work/tts/<lexicon>-unverified.json`，**需要人工试听**；可手工设 `"manual": true` 加 `voiceText` 换一个拼写（如 the /ðiː/ 用 "thee"）。词尾 s / z 清浊识别不可靠，不在核验范围内。任何时候都可以用 `node scripts/check-pron-audio.mjs <lexicon>` 重查全部词头音频。
  4. 页面播放：有录音的词条只播录音；录音播放失败时**不回退**到设备语音（设备语音不按原书音标读）。
- **按 Scan 标注显示（#133）**：「认识」的词头绿色，释义等详细内容默认收起，词头行右侧「展开」可看；「不认识」的词头红色，默认展开，可手动「收起」。Scan 没做或没做完时，没标的词按「不认识」显示，顶部计数注明还有几个没标。在 Scan 里改了标注，Study 的颜色和展开 / 收起随之更新。原「遮住释义」开关由 Scan 取代，已去掉。
- 列表顶部按字母分组锚点（约 3 组），不强制分组学习。

### 3.3 Quiz 标签

- **一个大题一页，共 6 页**（不是一题一页：每天约 40 个空，一题一页要点 40 次「下一题」；也不是整天一页：太长、键盘遮挡更严重）。沿用 KET / PET 一页多题的分页器：每页一个点，上方标 P1–P6、点里是题号范围（如 6–20），各 Part 之间有分隔线；页内标题「Part N. 原书指令」并显示完成数（#114）。整天只提交一次。
- **页内布局**：一、二、四、五 每题一行（题干左、输入框右；四、五在句中就地填空）；三 每题一组槽位；六 每题一张卡、多行文本框。
- **输入**：
  - 电脑和 iPad **默认键盘输入**（主动回忆，对中考笔试迁移最好）。
  - 英文框关闭 iOS 自动纠错 / 自动大写 / 拼写检查（`autocapitalize="none" autocorrect="off" spellcheck="false"`），中文框不关输入法。
  - **Enter / Tab 跳到下一空**，Shift+Tab 回上一空；iPad 上 `enterkeyhint="next"`，最后一空为 `done`；最后一空回车聚焦「下一大题」，不直接提交。
  - ~~**提示（可选）**~~：**已暂时取消（#115，体验不好）**。服务端 `/api/rc/hint` 与半分判分（决定 4）保留，界面不再提供，重新设计后再开放。
- **iPad 屏幕键盘**（我们的外壳 body 固定、`.app-scroll` 内部滚动，正好可控）：监听 `visualViewport`，键盘弹出时给 `.app-scroll` 加底部留白、隐藏底部翻页栏；聚焦后约 300 ms 把当前空滚到可视区中部；当前题干在滚动容器内 `position: sticky`；收起键盘后归位。必须在 iPadOS 真机（含外接键盘）验证。
- ~~**语音输入**~~：**已暂时取消（#116，先把键盘输入做好）**。服务端 `/api/rc/transcribe` 保留，界面不提供。原设计：每个**中文释义框**和**中译英文本框**旁一个麦克风按钮；点一下开始、再点一下停止（15 秒自动停），识别结果填入框中，学生可以修改，确认后才算作答。**拼写类空格（一的英文、二、三的英文、四、五）不提供语音**——语音识别返回的是正确拼写，会绕过拼写练习。翻译用语音作答的，在结果页标「语音作答」。
- **提交与结果**：沿用 Quiz 结果页（通过 / 未通过、正确率、View Answers / Try Again 及剩余次数）。**记分显示（#140）**：每个大题显示「答对题数 / 题数」（如 Part 1: 1/33），总分四舍五入为整数（如「得分 3 / 100（60 分及格）」），合集列表里的得分也取整；逐题只标对 / 部分正确 / 错，不显示每题分值（高考词汇部分空的分值是 0.88 这类小数）。复盘时逐空标对错，错空旁显示正确答案和「查看词条」，点开用 Vocabulary 词卡弹层显示该词手册内容；六题显示参考译文和判分要点。**Try Again 只重做错题。**
- **复习（下一期）**：错题 + 「不认识」的词进入错题本，次日打开时先复现，再按 1 / 3 / 7 天间隔。

## 5. 语音识别（ASR）选型

用火山 TTS 合成两种中国口音声音（女声、男声）× 32 条（中文释义 12、英文句子 10、中英混说 4、单词 6），每条另加约 12 dB 噪声，共 128 段，测我们现有 SiliconFlow 账号上的全部 ASR 模型：

| 模型 | 中文字错率 | 英文词错率 | 中英混说 | 单词全对 | 加噪影响 | 中位延迟 |
|---|---|---|---|---|---|---|
| **Qwen/Qwen3-ASR-1.7B** | **0%** | **0%** | **0%** | **100%** | 无 | **215 ms** |
| XingChenASR-V3.2-Ultra | 5.6% | 0% | 0% | 100% | 无 | 718 ms |
| XingChenASR-V3.2 | 0% | 0% | 0% | 79% | +1.6% | 512 ms |
| SenseVoiceSmall（口语题现用） | 1.0% | 0.6% | 4.1% | 96% | +0.7% | 1950 ms |

- **推荐 Qwen3-ASR-1.7B（SiliconFlow）**：准确率最高、最快，接口与现有 `server/speak.ts` 相同（只换 `ASR_MODEL`），不新增服务商。顺带建议口语题也换成它。
- 火山 / 豆包流式识别 2.0（调研中的另一首选，支持流式和热词）：我们的火山应用**未开通**语音识别（接口返回 403），需要在火山控制台开通后才能测；第一版用「说完再识别」的交互，Qwen3-ASR 已够快，可以不等。
- 局限：合成语音不是学生真人。上线前请 10–20 名初中生各录约 20 条（中文释义 + 英文句子）做一次复核；单价请以 SiliconFlow 控制台为准。

## 6. 生产流程（审定后按「已有类型」路径批量生产）

1. 词库：OCR 文本 + 页图 → 按 2.1 结构化（脚本先切分词条，agent 只做结构化和疑难行，按字母分批），校验：条目编号连续、每条有词头/音标/义项、例句中词头有下划线。
2. 70 天：按 2.2 结构化题目；书末答案逐题比对（新写 `check-vocab.ts`，同 `check-exam` 思路）；`wordRange` 与词库对齐。
3. 音频：词头 + 例句用火山 TTS 生成（约 1,800 词条 × 词头 + 1–3 例句）。
4. 先做第 1 天和对应词条做试点，你和审核人看过后再批量。
5. 原书错误照旧开 errata issue；key 一律 `reviewStatus: pending`。

## 7. 调研依据（节选）

- 主动提取 vs 重读：Karpicke & Roediger 2008 及复制研究（Söderstrøm & Bjork 2016）；数字闪卡提取练习（2025，PMC12649105）；学习时间短时「重读 + 测试」组合最好（2023）。
- 回忆 vs 识别：Nakata 2016（IRAL）；Laufer 词汇知识层级。选词块会把回忆降为识别（TypeLingo、Duolingo 博客）。
- 平台做法：Anki（每日新词默认 20）、Quizlet Learn、Vocabulary.com、墨墨 / 不背单词（单卡 + 自评）、Oxford / Cambridge 词典条目版式。
- iPad 键盘：WebKit 不支持 `interactive-widget`、VirtualKeyboard API；`visualViewport` 做法与 iOS 26 `offsetTop` 问题。
- 语音：豆包语音计费与 2.0 发布、Qwen3-ASR、SiliconFlow 转写 API、Web Speech API 在 iPad/国内的限制。
- 完整来源列表见调研报告（#110 评论）。

## 10. 高考考纲词汇（`gkv`，2026-10-24）

同一类型的第二本书：《2027年上海市高考英语词汇用法手册》+ 配套综合练习（125 天）。制作规范 [production-brief-gkv.md](production-brief-gkv.md)。
- 每天固定四个大题：一 单词默写（30%）、二 词组默写（30%）、三 首字母填空（20%）、四 句子翻译（20%）——全部是已有交互（`textEntry`、`extendedText` + `requiredWord`），无新题型。分值按原书百分比均分到每题（一：30 ÷ 34，不取整；显示时四舍五入）。
- 音频按 3.2 节的发音标准（#131）生成：`content/lexicons/gkv/pronunciations.json` → `node scripts/tts.mjs --lexicon gkv`（`--jobs` 并发，默认 4）。印了两个及以上音标的词条，词头按每个音标依次读（见 3.2），例句交给声音，需要时人工指定（`manual: true`）。
- 词条比中考多「辨析」（`compare`）和 ▲ 补充词（`supplement`）；三种标记的含义写在 `content/lexicons/gkv/lexicon.json`，与中考不同。
- item id 三位数（`gkv-d001`）。
- 第一批样例：第 1 天（a – ache，词条 1–34）+ 第 2 天（achieve – advanced，词条 35–68）。
- 全部 125 天于 2026-11-03 批量生产完成（中考第 2–70 天同批），见 [docs/handoff/production-handoff.zkv-gkv-full-2026-11.md](handoff/production-handoff.zkv-gkv-full-2026-11.md)。
- 手册第二部分的词组不属于任何一天（综合练习只按第一部分单词分天），本期不生产。
- 少数词条落在两天的印刷范围之间（中考 departure；高考 specialised、stability）：词条已录入词库，但不属于任何一天，学习页不显示，待人工决定是否并入相邻一天。
