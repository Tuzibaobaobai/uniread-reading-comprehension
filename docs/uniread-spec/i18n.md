---

> 适用仓库：`uniread-reading-comprehension`  
> 目标：所有**用户可见 UI chrome** 走 i18next 配置；支持 `zh-CN` / `en-US` 切换。  
> **不做**：`postMessage` / 考试 runtime 协议（由 BE 转换层注入）。

## 0. 背景与边界

| 层 | 职责 |
|---|---|
| 本仓库（RC） | 视觉、交互、文案；`t('key')` 取文案；导出 `applyExamLocale` 供打包入口调用 |
| `ureading-be` | `rc-entry` + `client.mjs` 收 `init` / `locale.set`，再调 `applyExamLocale` |
| `ureading-fe-web` | `mountResource` 把当前语言写入 `init`，热切换发 `locale.set` |

本仓库**不得**监听 `window`/`port` 上的 `uniread.exam.*`。语言切换 API 仅是普通函数，由 BE 的包装入口在协议层调用。

## 1. 依赖与目录

```bash
npm install i18next react-i18next --save
```

建议结构：

```
src/i18n/
  config.ts          # i18n.init
  index.ts           # re-export + normalizeLocale + applyExamLocale
  locales/
    zh-CN.json
    en-US.json
```

在 `src/main.tsx` 顶部：`import '@/i18n'`（或 `./i18n`）。  
使用 `initReactI18next` 后，组件里 `useTranslation()` 即可；不必强行包 `I18nextProvider`（与 FE 一致即可）。

## 2. 语言约定

- 支持：`zh-CN`（默认 / fallback）、`en-US`
- `normalizeLocale(raw?: string): 'zh-CN' | 'en-US'`
  - `en*` → `en-US`
  - 其余（含空）→ `zh-CN`
- `applyExamLocale(locale: string): Promise<TFunction>`（或返回 `changeLanguage` 的 Promise）
  1. `const lng = normalizeLocale(locale)`
  2. `document.documentElement.lang = lng`
  3. `return i18n.changeLanguage(lng)`

独立预览（Vite）：可读 `localStorage.getItem('rc.locale')` 作为初始 `lng`；**不要**用浏览器语言检测强行覆盖产品默认中文，除非产品明确要求。

iframe 产物：初始语言由宿主经 BE 桥下发；RC 侧只保证 `applyExamLocale` 可用。

## 3. 文案规则

### 必须进 locale 文件

- 按钮、标题、提示、空态、错误提示、`aria-label`、`placeholder`
- 模式说明（练习/考试）、成绩报告表头、计时文案
- `DAY_ZH` / `PAPER_ZH` / `SKILL_ZH` / `examStatusLabel` / 评分维度名（`content`/`organisation`/…）等 **UI 映射表**

### 不要当 UI chrome 强行翻译

- 题目内容、文章正文、选项文本（内容数据）
- 内容字段如 `rubricZh` / `tipsZh` 的**值**（标签「要点：」「语言点：」要 i18n）
- 代码注释、测试断言（除非为通过编译必须改调用签名）

### 禁止

- 在 JSX/TS 里新增长段中英硬编码用户文案
- 为「方便接入」加 `postMessage` 监听

## 4. Key 命名（建议）

按域分层，zh / en **同一套 key**：

| 前缀 | 用途 |
|---|---|
| `common.*` | 返回、取消、关闭、加载失败… |
| `playlists.*` | 合集列表页 |
| `playlist.*` | 合集详情 / 套卷列表 |
| `reader.*` | 作答壳：导航、提交、标记、材料/题目 tab… |
| `exam.*` | ModeDialog、SwitchMode、成绩报告、换算表、计时 |
| `speaking.*` | 口语录制提示与按钮 |
| `audio.*` | 播放器 aria |
| `paper.*` | `reading_writing` / `reading` / … |
| `day.*` | `mon`…`fri` |
| `skill.*` | reading/writing/listening/speaking |
| `examStatus.*` | 练习中 / 考试中 / 原始分文案模板 |
| `judge.*` | AI 评分标签、维度、MET 状态 |
| `interaction.*` | 各题型 hint、空格 aria、连词成句… |

插值用 i18next：`t('exam.timer.minutes', { count: n })`，避免字符串拼接散落。

用搜索确认无残留用户可见中文（注释除外）：

- `src/reader/interactions.tsx`
- `src/reader/ExamPane.tsx`（若有文案）
- `src/components/Rich.tsx`（如「批注：」aria）
- `src/lib/labels.ts` → 改为 `t('paper.xxx')` / helper，调用方传入 `t` 或使用 `i18n.t`
- `src/lib/exam-status.ts` → `examStatusLabel(s, t)` 或内部 `i18n.t`；更新所有调用方

组件内：`const { t } = useTranslation()`。  
纯函数（无 hooks）：`import i18n from '@/i18n'` 后 `i18n.t(...)`，或显式接收 `TFunction`。

## 6. 实现步骤（Agent 执行顺序）

1. 安装依赖，建 `src/i18n/*`，`main.tsx` 引入。
2. 先落齐 `zh-CN.json`（从现有中文抽 key），再补完整 `en-US.json`（自然、短、考试产品语气）。
3. 逐文件替换硬编码；`labels` / `exam-status` 一并改。
4. `npx tsc -b` 修类型。
5. 本地 `npm run dev`：改 `localStorage.rc.locale` 为 `en-US` 刷新，抽查列表页 + 作答壳 + 模式弹窗。
6. 自检：`rg '[\u4e00-\u9fff]' src --glob '!*.test.ts' --glob '!*.test.tsx'`，剩余应为注释或内容字段引用说明。

## 7. 验收标准

- [ ] `zh-CN` / `en-US` key 集合一致（无一侧缺 key）
- [ ] UI chrome 无硬编码用户文案
- [ ] 导出 `normalizeLocale`、`applyExamLocale`；**无** postMessage
- [ ] `tsc -b` 通过
- [ ] 独立预览可切换语言；不破坏现有路由与作答逻辑

## 8. 与上下游的衔接（只读知晓）

- BE 指南：`ureading-be/docs/agents/exam-rc-locale-bridge.md`（转换时调 `applyExamLocale`）
- FE 指南：`ureading-fe-web/agents/exam-iframe-locale.md`（`init` / `locale.set` 下发语言）

RC 完成 i18n 后，需重新走 BE `build_runtime` 出新 artifact，FE 才能在 iframe 里看到语言切换效果。
