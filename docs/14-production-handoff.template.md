## 收到此模板后

1. 将本文件与`14-agent-production-rules.md`放在生产项目的同一目录；显式要求Codex或Claude Code读取两者。完整任务说明在规约第10节。
2. 提供本次套题范围、实际项目目录、已有内容／源码、PDF／答案册／资产位置和交付目录；没有的材料写暂缺。先按规约检查缺口，再按确定的范围补齐。
3. 复制为`production-handoff.<本次任务标识>.md`后填写，保留空白模板。删除示意行，未知写“待补／未验证”，不伪造数据；不适用项说明理由。
4. 文件位置使用接收方可定位的项目相对路径或受控材料标识，附交付版本。本文只引用私有答案位置，不粘贴答案、密钥或带Token的链接。
