# 05 · UI 规范：页面结构与行为

本文只描述**页面结构、组件组成和交互行为**，不写具体视觉值。
- 视觉的唯一来源：Figma 设计系统，组件与链接见 [design/figma-registry.md](design/figma-registry.md)（[ADR-0007](decisions/ADR-0007-figma-design-system.md)）
- 代码中的视觉值只来自 [`src/styles/tokens.css`](../src/styles/tokens.css)；token 命名按登记表中的映射规则，组件中不得出现颜色等字面量
- 主色 `--accent` = Figma `color/6`；产品决定：界面文字用中文
- 尚无 Figma 组件的部分（标“待提供”）暂沿用现有实现，组件提供后替换

## 页面

### 1. Playlists 列表（组件：Playlists 卡片，待提供）
- 卡片网格：PC 4 列、iPad 横屏 3 列、竖屏 2 列
- 卡片：封面图（保持比例裁剪）、标题（单行省略）、`共60篇 · L2–L4` 元信息、题型图标行
- 点击卡片进入 Playlist 详情

### 2. Playlist 详情（组件：`Playlist`）
- 左上：返回按钮 → Playlists
- 左栏（sticky，约 1/3 宽）：信息面板，含封面、标题、分隔线、词数与难度（两端对齐）、简介（2 行省略）、「收藏」按钮。不做分享、统计按钮
- 右栏：`合集（60）` 标题；按周分组（`Week 1` 小标题）；行 = 序号 + 16:9 缩略图 + 标题（只显示文章标题，不加 Week／星期前缀，#9）+ 元信息 `126 单词 · L4 · 3 questions · 6 min` + **进度条**（未开始 / 进行中 / 已完成）；已完成显示得分
- 无图片的文章：生成文字卡缩略图（playlist 主题色 + 星期标签 + 标题）

### 3. 阅读理解页
- **顶栏**（组件：`Header`，只用返回按钮 + 标题）：返回 → Playlist 详情；标题为 item `title`（不加 Week／星期前缀），单行省略
- **左栏**（组件：`Article Text` 的文字样式）：独立滚动，顺序为
  1. 标题
  2. 信息框：两列 key–value（语篇类型、词数、难度、建议用时、主题语境、内容要求），导读整行
  3. 图片
  4. 正文：保留原书格式。高亮词、下划线词、中文括注、空格芯片分别使用对应 token 样式
  5. Words & Expressions：标签标题 + 列表（词、音标、词性、中文）
- **右栏**（组件：`Quiz`）：题卡，一次一题
  - 顶部：节标题（`I. Decide whether…`），每道题上方都显示，照录原书大题提示
  - 题干 + 作答区：各题型见 [02 §3](02-question-types.md#3-各题型交互)；选项行用 `Option-text-item`
  - 底栏（组件：`Quiz-pagination`）：上一题（首题禁用）/ 题号分页（当前题、已答标记）/ 下一题；最后一题为「提交」，未答完时为弱化态
    - 题号放不下时（如 24 道小题）：题号条可横向滚动（触屏滑动；PC 鼠标竖向滚轮也会横向滚动）；有被遮住题号的一侧出现“更多”按钮（箭头 + 被遮住的题数，如 “+8”，触控区 ≥ 44px），点击翻过约一屏；该侧边缘渐隐提示还有内容；切换题目时当前题号自动滚到中间。题少时不出现按钮。实现：`src/reader/QuestionStrip.tsx`
- **结果**：提交后右栏顶部显示结果卡（待提供）：得分、正确率、用时；题号分页变为结果（GitHub #128）：单道客观题显示对错图标；有评分的题（写作、口语、含书写格的表格）显示“得分/总分”（如 15/20），解析标题显示“得分 x / y”；整页作答的客观题 Part 显示“对的题数/总题数”（如 3/5）；题卡进入复盘态，选择题解析展开在正确选项下方；表格填空（`view: table`，#127）整表一页：勾选格为下拉框（点开后点选，非原生 select），书写格为文本框，提交后每格标对错（书写格由 AI 按参考答案判对错）、题号条显示“对的格数/总格数”、表格下方逐格列出答案与解析

## 交互细节
- 题目切换时，左栏若有对应空格 / 证据，平滑滚动并短暂高亮
- 焦点环仅键盘导航时显示（`:focus-visible`）
- 触控目标 ≥ 44px，输入框字号 ≥ 16px（可访问性与 iOS 要求，不属于视觉设计）

## 响应式
见 [02 §5](02-question-types.md#5-响应式)：按容器宽度在 50/50 分栏与「文章 / 题目」切换之间切换。

整体缩放（GitHub #62，UniRead `ui-style-kit`）：设计宽度 1000px，CSS 写 px，构建时由 `postcss-mobile-forever` 转为 vw；视口小于 1000px 时整页（含字号）等比缩小，≥ 1000px 保持原尺寸。RC 的断点切换照常叠加生效。全屏壳：`body` 固定铺满，页面在 `.app-scroll` 内滚动，`#root` 留出安全区；viewport 禁止用户缩放（`maximum-scale=1`）。
