# 05 · UI 规范（UniRead 风格）

Figma 暂不可用，依据 [`screenshots/`](../screenshots/) 中 5 张 UniRead 页面截图实现。所有视觉值集中在 [`src/styles/tokens.css`](../src/styles/tokens.css)，Figma 恢复后只需替换 token。

## 设计 token（截图取值，待 Figma 校准）
| token | 值 | 用途 |
|---|---|---|
| `--bg-page` | `#F4F5F8` | 页面底色（浅灰蓝） |
| `--bg-card` | `#FFFFFF` | 卡片 / 面板 |
| `--text-primary` | `#1F2329` | 标题、正文 |
| `--text-secondary` | `#8A8F99` | 元信息、次要文字 |
| `--text-tertiary` | `#C2C6CE` | 禁用 |
| `--accent` | `#F07B3F` | 单选圈、焦点、强调（UniRead 橙） |
| `--border` | `#E6E8EC` | 分隔线、描边按钮 |
| `--radius-card` | `24px` | 大卡片 |
| `--radius-thumb` | `12px` | 缩略图 |
| `--radius-pill` | `999px` | 胶囊按钮、圆形按钮 |
| `--shadow-card` | `0 4px 24px rgba(31,35,41,.06)` | 卡片阴影 |
| 字体 | Source Sans 3（自托管 @fontsource）+ 系统中文字体 PingFang SC / Microsoft YaHei | 不用 Google Fonts（国内不可用） |
| 正文字号 | 22px / 行高 1.6（文章）；题干 22px 粗体；选项 20px | 来自阅读页截图 |

## 页面

### 1. Playlists（`playlist thumbnails.png`）
- 卡片网格（PC 4 列、iPad 横屏 3 列、竖屏 2 列），卡片白底大圆角 + 阴影
- 上部封面图（顶部圆角，保持比例裁剪）
- 下部：标题单行省略（`沪教上海版 六年级（上）课后…` 样式）；`共60篇 · L2–L4` 灰色小字；题型小图标行（灰色图标）

### 2. Playlist 详情（`playlist介绍和items.png`）
- 左上：圆形白色返回按钮（阴影，← 图标）
- 左栏（sticky，约 1/3 宽）：浅色渐变底的圆角面板，内含大封面（圆角）、标题（粗体）、分隔线、`7,560 单词` 与 `L1–L5` 两端对齐、简介（灰色，2 行省略）、白色「收藏」按钮（☆ 图标）
- 右栏：`合集（60）` 粗体标题 + 分隔线；按周分组（`Week 1` 小标题）；行 = 序号（灰色）+ 16:9 圆角缩略图 + 粗体标题（`Week 1 Monday …`）+ 元信息 `126 单词 • L4 • 3 questions • 6 min`；已完成显示得分徽标，进行中显示“进行中”
- 无图片的文章：生成文字卡缩略图（playlist 主色浅底 + 星期标签 + 标题）

### 3. 阅读理解界面
- 顶栏（`阅读理解页面的回到playlist的button.png`）：圆形白色返回按钮 + 灰色 item 标题（`displayName`）
- 左栏（`阅读理解页面文章样式.png`）：白色面板，独立滚动，细滚动条；顺序：
  1. 标题（大号粗体）
  2. 信息框（浅底圆角块，两列 key–value：语篇类型、词数、难度、建议用时、主题语境、内容要求，导读整行）
  3. 图片（圆角）
  4. 正文（22px，段间距 1em；高亮词 = 强调色文字；下划线词；中文括注灰色小字；空格为胶囊芯片）
  5. Words & Expressions（标签标题 + 列表：词 粗体、音标灰、词性斜体、中文）
- 右栏（`阅读理解页面题目样式.png`）：白色大圆角卡片
  - 顶部：节标题（`I. Decide whether…`，灰色小字）
  - 题干：`1. Where is Amy from?` 粗体
  - 选项：橙色描边圆圈 + 文字，选中为实心橙圈
  - 底部分隔线 + 底栏：左「上一题」（胶囊描边，首题禁用为浅灰），中间题号分页（当前题浅灰圆底；已答题号下方小圆点），右「下一题」/ 最后一题「提交」（主色实心）
- 结果：提交后右栏顶部显示结果卡（得分大号数字、正确率、用时），题号分页变为 ✓/✗ 色点，题卡进入复盘态

## 交互细节
- 返回按钮：阅读页返回 playlist 详情；详情页返回 playlists
- 题目切换时，左栏若有对应空格/证据，平滑滚动并高亮 1.2s
- 焦点环：2px `--accent`，仅键盘导航时显示（`:focus-visible`）
