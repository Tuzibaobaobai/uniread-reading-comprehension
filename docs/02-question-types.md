## 2. 通用交互原则
依据 IELTS 机考、TOEFL iBT、NAEP、Newsela、CommonLit 等成熟产品与 WCAG 2.2：
- **一题一页**（UniRead 样式）：右栏卡片一次显示一道题，底栏「上一题 / 题号分页 / 下一题」，最后一题「下一题」变「提交」
- **无拖拽依赖**：所有放置类操作用「点选-点放」；WCAG 2.5.7
- **触控目标 ≥ 44pt**、间距 ≥ 8px；输入框字号 ≥ 16px（防 iOS Safari 缩放）
- **不用原生 `<select>`**（iOS 选择器会遮挡文章）
- **作答过程中不判对错**，一次性提交
- 状态不只靠颜色：已答、正确、错误分别配图标
- 键盘：选项 `A–D` / `1–4`，`←/→` 切题，`Enter` 下一题

## 3. 各题型交互

| interaction | PC | iPad | 左栏联动 | 复盘（提交后） |
|---|---|---|---|---|
| `choice` | 整行可点的选项行，橙色描边圆点 | 同左，行高 ≥ 56px | 题干含下划线词时，点击题干词 → 左栏滚动并闪烁该词 | 正确项绿色 ✓；所选错项红色 ✗；解析 + 证据句在左栏高亮 |
| `trueFalse` | 两个大按钮 True / False | 同左 | 同上 | 同上 |
| `inlineChoice`（完形） | 题卡显示“第 n 空”与选项；左栏空格显示 `n` 或已选词 | 同左 | **双向**：当前题对应空格高亮；点左栏任一空格切到该题 | 左栏空格显示正确词，错误空格红色并显示所选 |
| `gapMatch` | 题卡顶部显示共享词库（已用项置灰并标空格号），点词即填入本题空格；多空题先点空格再点词 | 同左 | 同完形；左栏空格显示所填词/句首字母 | 每空：你的 / 正确；干扰项标“未使用” |
| `textEntry` | 题卡内输入框；首字母提示作为前缀显示 `n▢▢▢`；原词提示显示 `(develop)` | `autocapitalize=off autocorrect=off spellcheck=false enterkeyhint=next`；键盘弹出时保持输入框可见 | 文中/表中空格同步显示所填文字，点击切到该题 | 每空 ✓/✗ + 参考答案 |
| `match` | 左右两列卡片，点左项再点右项完成配对；配对项共享颜色边框与字母徽标（不画连线，触屏更稳定） | 同左，绝不要求拖线 | – | 正确对绿色，错误对红色并显示正确配对 |
| `extendedText` | 自适应文本框；有句子框架时显示框架 | 同左 | 点“定位原文”滚动到相关段落 | 显示参考答案与要点，学生自评“我答对了 / 还需努力”；不计入分数 |

## 4. 提交与结果
- 点「提交」：若有未答题 → 弹窗列出题号（可点击跳转），主按钮「继续作答」，次按钮「仍然提交」
- 结果卡：得分 `7 / 8`、正确率、用时 vs 建议用时；逐题对错一览（题号圆点 ✓/✗）
- 复盘模式：同一布局，题目锁定；显示正确答案、中文解析、左栏证据句高亮；「只看错题」切换；「重新作答」清空本次作答
- 自动保存：每次作答写入 localStorage；刷新后恢复到上次题号与答案

## 5. 响应式
- ≥ 1024px（PC、iPad 横屏）：左右 50/50，各自独立滚动
- < 1024px（iPad 竖屏、分屏）：顶部「文章 / 题目」分段切换；完形与选词类题在题目页顶部显示可折叠的文章片段（当前空格附近的句子）
- 按容器宽度判断，不按设备类型
