## 2. 通用交互原则
依据 IELTS 机考、TOEFL iBT、NAEP、Newsela、CommonLit 等成熟产品与 WCAG 2.2：
- **一题一页**（UniRead 样式）：右栏卡片一次显示一道题，底栏「上一题 / 题号分页 / 下一题」，最后一题「下一题」变「提交」
- **无拖拽依赖**：所有放置类操作用「点选-点放」；WCAG 2.5.7
- **触控目标 ≥ 44pt**、间距 ≥ 8px；输入框字号 ≥ 16px（防 iOS Safari 缩放）
- **不用原生 `<select>`**（iOS 选择器会遮挡文章）
- **作答过程中不判对错**，一次性提交
- 状态不只靠颜色：已答、正确、错误分别配图标或文字（可访问性要求）
- 键盘：选项 `A–D` / `1–4`，`←/→` 切题，`Enter` 下一题

## 3. 各题型交互

本节只描述行为。视觉（颜色、尺寸、状态样式）见 [设计系统登记表](design/figma-registry.md)，组件名以登记表为准。

| interaction | 组件 | 作答 | 左栏联动 | 复盘（提交后） |
|---|---|---|---|---|
| `choice` | `Option-text-item`（默认 / 悬停 / 选中） | 整行可点；单选 | 题干含下划线词时，点击题干词 → 左栏滚动并闪烁该词 | 正确项用「正确-展开」态，解析展开在其下方；所选错项用「错误」态；证据句在左栏高亮 |
| `trueFalse` | `Option-text-item`（True / False 两项） | 同 `choice` | 同上 | 同上 |
| `inlineChoice`（完形） | 题卡显示“第 n 空”与选项（`Option-text-item`）；左栏空格芯片（待提供） | 同 `choice` | **双向**：当前题对应空格高亮；点左栏任一空格切到该题 | 左栏空格显示正确词；错误空格标为错误并显示所选 |
| `gapMatch` | 词库芯片（待提供） | 空格上只显示所选选项的字母（如 “I”），不显示单词（#11）；题卡顶部显示共享词库，已用项标为已用并注明空格号；点词即填入本题空格；多空题先点空格再点词 | 同完形；左栏空格显示所填词 / 句首字母 | 每空显示你的答案与正确答案；干扰项标“未使用” |
| `textEntry` | 输入框（待提供） | 首字母提示作为前缀 `n▢▢▢`；原词提示显示 `(develop)`；iPad：`autocapitalize=off autocorrect=off spellcheck=false enterkeyhint=next`，键盘弹出时保持输入框可见 | 文中 / 表中空格同步显示所填文字，点击切到该题 | 每空对错标记 + 参考答案 |
| `match` | 连线卡片（待提供） | 左右两列，点左项再点右项完成配对；配对两项用同一配对标记（字母徽标）；不画连线，绝不要求拖线 | – | 正确对与错误对分别标记，错误对显示正确配对 |
| `extendedText` | 文本框、AI 批改卡（待提供） | 自适应高度；有句子框架时显示框架 | 点“定位原文”滚动到相关段落 | 提交后显示“正在批改…”，随后显示得分、要点 ✓/½/✗、中文反馈、语言纠错和参考答案；低置信度标“待老师确认”；judge 不可用时改为学生自评（不计分） |

题号分页（`Quiz-pagination`）：当前题、已答、提交后对错三种标记；最后一题“下一题”变“提交”，有未答题时“提交”为弱化态但仍可点击（触发未答提醒）。

## 4. 提交与结果
- 点「提交」：若有未答题 → 弹窗列出题号（可点击跳转），主按钮「继续作答」，次按钮「仍然提交」
- 结果卡（待提供组件）：得分 `7 / 8`、正确率、用时 vs 建议用时；逐题对错一览（题号对错标记）
- 复盘模式：同一布局，题目锁定；显示正确答案、中文解析（选择题嵌在正确选项下方，其他题型在题下方）、左栏证据句高亮；「只看错题」切换；「重新作答」清空本次作答
- 自动保存：每次作答写入 localStorage；刷新后恢复到上次题号与答案

## 5. 响应式
- ≥ 1024px（PC、iPad 横屏）：左右 50/50，各自独立滚动
- < 1024px（iPad 竖屏、分屏）：顶部「文章 / 题目」分段切换；完形与选词类题在题目页顶部显示可折叠的文章片段（当前空格附近的句子）
- 按容器宽度判断，不按设备类型
- 叠加 1000px 设计宽度的 vw 等比缩放（GitHub #62）：小于 1000px 时整页等比缩小，断点照常生效

## 6. 真题（KET / PET，`format: exam`）

题型尽量复用上面的交互；参考 Cambridge 官方机考（底部题号栏、计时、标记、写作实时字数）和 Cambridge 练习/考试两种模式。

| Part | 交互 |
|---|---|
| R&W 1 告示 | `choice`，告示图作为题目材料显示在左栏 |
| R&W 2 三篇短文配人 | `choice`，选项为三个人名 |
| R&W 3 长文 / 听力 3、4 | `choice` |
| R&W 4 选择型完形 | `inlineChoice`（同完形） |
| R&W 5 开放式完形 / 听力 2 笔记填空 | `textEntry`，空格在左栏材料（表格）中；示例 (0) 以文字呈现 |
| R&W 6 邮件、7 看图写故事 | `extendedText` + 字数下限计数；AI 按 Cambridge 写作标准评分（内容 / 条理性 / 语言各 0–5），界面注明“评分遵照 Cambridge 标准” |
| 听力 1 看图选择 | `choice` 图片选项，三张卡片并排 |
| 听力 5 人物配对 | 每人一道 `choice`，选项 A–H |
| 口语 | `speaking`：每个考官问题一页（#74，页码顺延，P1/P2 标出 Part）；逐句听题（TTS）→ 录音 → 回放 / 重录；提交后整段转写并按 Cambridge 口语标准评分（每个 Part 一个分数，显示在该 Part 最后一页；发音暂不评估） |

- **听力左栏**（#72）：所有 Part 的录音模块纵向排列（标题、说明、播放控件），录音不随题目切换而重新开始；当前题所在 Part 展开显示材料，提交后显示听力原文。题号条中每个 Part 的第一个题号上标“P1、P2…”，Part 之间有分隔线。
- **练习模式**：不限时；每个 Part 的录音可单独播放、暂停、拖动、±5 秒，同一时间只播一段，播完不自动播下一段；提交后看答案、解析、听力原文。
- **考试模式**：按官方时长倒计时（剩 5 分钟、1 分钟提醒，到时自动交卷）；听力点“开始播放听力”后按考试顺序连续播放各 Part（每段录音已含两遍），正在播放的 Part 高亮，不能暂停、拖动或重播，学生可以提前看后面的题；可标记题目；交卷后显示成绩报告：各 Part 得分 + Cambridge English Scale 估算（Cambridge 官方练习题换算表，标明“估算”）。
